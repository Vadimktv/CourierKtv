# Courier Voice Assistant

Прогрессивное веб-приложение для курьеров с голосовым вводом и распознаванием данных с фото чеков. Проект не требует сторонних UI-фреймворков и рассчитан на мобильные устройства с тёмной темой по умолчанию.

## Возможности

- **Голосовой ввод** — зажмите кнопку микрофона, говорите, отпустите для отправки. Смахивание/уход пальца отменяет запись.
- **Автоматическое заполнение** адреса, суммы и телефона из распознанного текста.
- **Быстрые действия**: звонок клиенту и построение маршрута в Яндекс.Навигаторе (с веб-фолбэком).
- **OCR чеков** — загрузите фото, данные заполнятся автоматически.
- **Работа в условиях плохого интернета** — минимальный бандл, без тяжёлых зависимостей.

## Быстрый старт

```bash
npm install
npm run dev
```

Сервер запустится на `http://localhost:3000` и отдаст статический фронтенд.

### Переменные окружения

Создайте файл `.env` или задайте переменные перед запуском:

```bash
OPENAI_API_KEY=sk-...
OPENAI_MODEL=whisper-1          # необязательно
GOOGLE_VISION_API_KEY=...        # ключ Google Cloud Vision API
OCR_SPACE_API_KEY=helloworld     # резервный ключ OCR.space (опционально)
MOCK_TRANSCRIBE_TEXT=...         # необязательный текст для офлайн-демо
MOCK_OCR_TEXT=...                # необязательный текст для офлайн-демо
PORT=3000                        # необязательно
```

Если ключи OpenAI/Google Vision отсутствуют, сервер вернёт содержимое переменных `MOCK_TRANSCRIBE_TEXT` / `MOCK_OCR_TEXT` (или пустую строку). Это удобно для локальной отладки без внешних API.

При отсутствии `GOOGLE_VISION_API_KEY` приложение автоматически переключится на бесплатный OCR сервис [OCR.space](https://ocr.space/). При желании можно задать собственный ключ через `OCR_SPACE_API_KEY` (по умолчанию используется демо-ключ `helloworld`).

### Скрипты npm

- `npm run dev` — запускает сервер Express-подобного приложения (`src/server/index.js`).
- `npm run start` — аналогично.
- `npm test` — быстрый smoke-тест парсера (`tests/parser.smoke.test.js`).

### Особенности реализации

- **Мини-Express**: из-за ограничений окружения используется лёгкая реализация Express API (`src/server/framework/mini-express.js`). Она поддерживает маршруты, middleware, JSON body parser и отдачу статических файлов.
- **Формат данных**: фронтенд отправляет аудио и изображения в Base64 (data URL). Это избавляет от `multipart/form-data` и сторонних библиотек.
- **Парсер**: извлекает адрес, сумму и телефон из любой фразы на русском. При отсутствии данных фронтенд выводит предупреждения.
- **Интерфейс**: адаптивный mobile-first дизайн, визуальные состояния кнопки записи как в Telegram.

## Проверка работы

1. Запустите `npm run dev`.
2. Откройте `http://localhost:3000` на мобильном устройстве или в браузере.
3. Разрешите доступ к микрофону и протестируйте удержание кнопки.
4. Для OCR выберите фото чека (желательно с печатным текстом).

## Безопасность

- API-ключи не сохраняются на клиенте.
- Запросы идут только на ваш сервер, который затем обращается к внешним сервисам.
- Размер JSON ограничен 20 МБ.
